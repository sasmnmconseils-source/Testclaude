# Simulateur d'Indemnités Kilométriques

Un simulateur web simple et élégant pour calculer les indemnités kilométriques selon le barème fiscal français.

## 📋 Description

Ce simulateur permet de calculer automatiquement le montant des indemnités kilométriques auxquelles vous avez droit en fonction de :
- Votre type de véhicule (voiture, moto, cyclomoteur)
- La puissance fiscale de votre véhicule
- La distance parcourue

Le calcul est basé sur les barèmes fiscaux français officiels.

## 🚀 Utilisation

### Lancement de l'application

1. Ouvrez simplement le fichier `index.html` dans votre navigateur web
2. Aucune installation ou serveur web n'est nécessaire

### Comment calculer vos indemnités

1. **Sélectionnez votre type de véhicule** :
   - Voiture
   - Moto (plus de 50 cm³)
   - Cyclomoteur (50 cm³ ou moins)

2. **Indiquez la puissance** (selon le type de véhicule) :
   - Pour une voiture : sélectionnez la puissance fiscale (3 CV, 4 CV, 5 CV, 6 CV, 7 CV et plus)
   - Pour une moto : sélectionnez la cylindrée (1-2 CV, 3-5 CV, plus de 5 CV)
   - Pour un cyclomoteur : aucune puissance à sélectionner

3. **Entrez la distance parcourue** en kilomètres

4. **Cliquez sur "Calculer"**

5. Le résultat s'affiche avec :
   - Le montant total de l'indemnité
   - Le barème appliqué
   - Le détail du calcul

## 📊 Barèmes utilisés

### Voitures

Les barèmes varient selon la puissance fiscale et la distance parcourue :
- Jusqu'à 5 000 km
- De 5 001 à 20 000 km
- Au-delà de 20 000 km

### Motos et cyclomoteurs

Les barèmes s'appliquent par tranches :
- Jusqu'à 3 000 km
- De 3 001 à 6 000 km
- Au-delà de 6 000 km

## ⚠️ Avertissement

Ce simulateur est fourni à titre informatif. Les barèmes fiscaux peuvent évoluer d'une année à l'autre. Vérifiez toujours les barèmes officiels en vigueur pour l'année fiscale concernée auprès de l'administration fiscale française.
