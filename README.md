# Simulateur de Charges Sociales

Un simulateur interactif pour calculer les charges sociales en France.

## 🎯 Fonctionnalités

- **Calcul précis** : Calcule automatiquement les cotisations salariales et patronales
- **Secteurs multiples** : Supporte le secteur privé et public
- **Statuts variés** : Cadre et non-cadre
- **Interface moderne** : Design responsive et convivial
- **Détails complets** : Affiche le détail de toutes les cotisations

## 📊 Ce qui est calculé

### Cotisations Salariales
- Sécurité sociale (maladie, vieillesse)
- Retraite complémentaire (AGIRC-ARRCO)
- Assurance chômage
- CSG/CRDS
- Autres contributions spécifiques selon le statut

### Cotisations Patronales
- Allocations familiales
- Sécurité sociale
- Retraite complémentaire
- Accidents du travail
- Formation professionnelle
- Taxe d'apprentissage
- Autres contributions

### Résultats
- **Salaire brut** : Le salaire mensuel brut saisi
- **Salaire net** : Le salaire après déduction des cotisations salariales
- **Coût total employeur** : Salaire brut + cotisations patronales

## 🚀 Utilisation

1. Ouvrez le fichier `index.html` dans votre navigateur web
2. Saisissez votre salaire brut mensuel
3. Sélectionnez votre statut (Cadre/Non-cadre)
4. Choisissez votre secteur (Privé/Public)
5. Cliquez sur "Calculer"

## 💡 Notes importantes

- Les taux de cotisations sont basés sur les moyennes 2024
- Les calculs sont donnés à titre indicatif
- Les taux réels peuvent varier selon votre situation spécifique
- Pour une estimation précise, consultez votre service de paie ou l'URSSAF
